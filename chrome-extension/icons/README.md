# Extension Icons

This folder should contain the following icon files:

- `icon16.png` - 16x16 pixels
- `icon32.png` - 32x32 pixels
- `icon48.png` - 48x48 pixels
- `icon128.png` - 128x128 pixels
- `error.png` - 128x128 pixels (red icon for errors)
- `warning.png` - 128x128 pixels (yellow icon for warnings)

## Generating Icons

You can use any image editing tool to create these icons. They should have:
- Transparent background
- Simple, recognizable design
- High contrast for visibility

Recommended design:
- Main icon: Monitor/screen with "200" text
- Error icon: Red circle with X or exclamation mark
- Warning icon: Yellow triangle with exclamation mark
