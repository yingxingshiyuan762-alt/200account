アイコンファイルについて / About Icon Files
================================

この拡張機能を使用するには、以下のアイコンファイルが必要です：

必須ファイル / Required Files:
- icon16.png (16x16 pixels)
- icon32.png (32x32 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

オプション / Optional:
- error.png (128x128 pixels) - エラー通知用の赤いアイコン
- warning.png (128x128 pixels) - 警告通知用の黄色いアイコン

アイコンの作成方法 / How to Create Icons:
========================================

方法1: オンラインツールを使用
---------------------------
1. https://www.favicon-generator.org/ にアクセス
2. 画像をアップロードまたはテキストで生成
3. 必要なサイズを選択してダウンロード
4. このフォルダに配置

方法2: 既存の画像から生成
-----------------------
1. Photoshop, GIMP, Paint.NETなどの画像編集ソフトを使用
2. ベース画像を作成（推奨：512x512）
3. 各サイズにリサイズして保存
4. このフォルダに配置

方法3: Pillowライブラリを使用（Python）
-------------------------------------
chrome-extension フォルダで以下を実行：

    pip install pillow
    python create_icons.py

一時的な対処法 / Temporary Workaround:
=====================================

アイコンファイルがない場合、Chrome拡張機能はデフォルトアイコンを使用します。
機能は正常に動作しますが、視覚的な識別性が低くなります。

推奨アイコンデザイン / Recommended Design:
=========================================

メインアイコン（icon*.png）:
- 背景色: ブルー系（#667eea）
- テキスト: "200" または モニターアイコン
- スタイル: モダン、フラットデザイン

error.png:
- 背景色: 赤（#dc2626）
- シンボル: "×" または "!" 
- 目的: エラー通知の視認性向上

warning.png:
- 背景色: オレンジ/黄色（#f59e0b）
- シンボル: "!" または "▲"
- 目的: 警告通知の識別

サンプルリソース / Sample Resources:
====================================

無料アイコンサイト:
- https://www.flaticon.com/
- https://iconmonstr.com/
- https://icons8.com/

カラーパレット:
- Main: #667eea (Blue)
- Error: #dc2626 (Red)
- Warning: #f59e0b (Orange)
- Success: #10b981 (Green)

重要 / Important:
================

アイコンファイルは透過PNG形式で保存してください。
Chrome拡張機能の視覚的な品質を向上させるため、可能な限り高品質なアイコンを使用することを推奨します。
